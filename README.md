A program that writes one out-of-office auto-reply, at most 120 characters, as if a houseplant had written it — the fern ignored since March, now unionized, with the cactus covering the inbox on a diet of pure neglect.

Run: `node main.ts` — writes the reply to `/output/entry.txt` (UTF-8, 1–120 characters).
